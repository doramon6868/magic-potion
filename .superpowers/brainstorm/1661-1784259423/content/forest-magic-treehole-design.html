魔法树洞 · 森林玩耍区视觉方案

方案 B：把圆角卡片改成有机树冠轮廓，同时与下方游猎区形成鲜明对比

核心概念

森林区不再是一块信息面板，而是水晶球世界向右侧自然延伸出的一个“树洞入口”。顶部是树冠起伏的轮廓，底部有草地覆盖，宠物站在林间空地上。整体情绪是柔和、安全、充满生机的。

与游猎区的对比
维度 森林区（本次改造） 游猎区（后续改造方向）
轮廓有机树冠 + 草地起伏尖锐岩石 / 荆棘直线
主色冷绿 + 金粉点缀暗红 + 炭黑
动效摇摆、飘落、萤火虫聚集闪烁、震动、火光脉冲
情绪安全、生长、治愈危险、紧张、未知
关键视觉元素
  • 背景层次：远景蓝绿雾气 → 中景主林绿 → 近景深绿地面，形成纵深。
  • 顶部树冠：用 SVG 剪影做出 2–3 个圆润起伏，颜色比主背景深半档，让容器看起来像被树冠框住。
  • 底部草地：一条略深的地面色带 + 几丛小草，左侧的树可以下探 5–10px 营造“探出边界”的错觉。
  • 林间漏光：从顶部中心向下的淡金色径向光晕，宠物区域最亮，自然形成视觉焦点。
  • 魔法粒子：3–5 个缓慢漂浮的萤火虫/孢子，仅在宠物在场时显示，避免空状态过吵。
  • 信息层级：标题左对齐，安全标签右对齐；收益以宠物脚下浮动提示泡或头顶粒子形式出现，不再占底部卡片。
交互反馈
  • 拖拽高亮：边框和整体脉冲改成“草丛向四周轻微摆动 + 萤火虫向中心聚集 + 光晕变亮”。
  • 宠物放入：触发一阵花瓣/叶子被惊起的粒子效果，强调“安全、活泼、自然”。
  • 空状态：显示一片飘落叶子 + “把宠物拖到这里玩耍”的短句，而不是孤零零的灰色文字。
技术约束
  • 保持组件在右侧 260px 面板内，高度维持约 200px，不挤压游猎区空间。
  • 树冠轮廓用 border-radius 或 SVG clip-path 实现，确保响应式下不会变形。
  • 所有新粒子用纯 CSS 动画，不引入新依赖。
