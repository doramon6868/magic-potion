魔法树洞 · 详细设计规格

基于你的反馈：SVG 树冠外包、emoji 动态小生物、冒泡收益

一、SVG 树冠轮廓设计需求

这个 SVG 将作为 OutdoorPlay.vue 容器的顶部装饰层（也可作为 clip-path 参考），下面是给外部工具/设计师的完整需求：

  • 画布尺寸： 宽度 260px（与右侧面板等宽），高度 40–50px，视口 0 0 260 48。
  • 风格： 手绘卡通，粗描边（2–3px），与现有 TreeDecoration 一致。线条可以略带抖动，不要完美的贝塞尔曲线。
  • 结构：
    • 底部是一条平直的“枝干/林冠底线”，作为与下方内容的分界线。
    • 上方有 3 个圆润的“树冠团”，像云朵一样连在一起：左侧一团较小，中间一团最高最大，右侧一团中等。
    • 每个树冠团内部用 2–3 条弧线暗示叶片层次，不要画单一片叶子。
  • 配色：
    • 填充：比主背景深半档的绿色，例如 #4a8b6a，带一点半透明（80–90% 不透明），让后面能透出淡淡的光晕。
    • 描边：与游戏主描边色一致 #612315（或 --mp-ink），2.5px。
    • 点缀：在树冠右侧或中间缝隙加 1–2 个金色小圆点（魔法果实），直径 4–5px，描边同色系。
  • 可切分： 请导出为扁平 SVG（单一路径或 2–3 个路径），不要包含复杂渐变，方便我们后续用 CSS 变量调整颜色。

二、emoji 动态小生物规格

所有动态生物都用 emoji + CSS 动画实现，不引入额外图片资源。

生物 Emoji 数量 动画 出现时机
萤火虫 / 魔法孢子 ✨ 或 🌟 3–4 个 缓慢上下漂浮 + 明暗闪烁，周期 4–6s，不同相位 始终显示（营造森林氛围）
蝴蝶 🦋 1–2 只 沿柔和曲线飞行，翅膀轻微缩放（scaleX 交替），周期 8–10s 宠物在场时显示
小瓢虫 / 甲虫 🐞 1 个 沿底部草丛缓慢爬行，偶尔停顿，周期 12s 始终显示
飘落花瓣 / 叶子 🌸 或 🍃 2–3 片 从顶部缓慢旋转飘落到底部，周期 6–8s，循环 始终显示

注意： 所有生物使用绝对定位，pointer-events: none，不影响拖拽交互。动画默认播放，尊重 prefers-reduced-motion。

三、冒泡收益提示设计

当宠物在森林区玩耍时，每隔一段时间头顶冒出一个心情/经验气泡，像 RPG 里的浮动战斗文字。

  • 触发时机： 宠物在场时，每 5–8 秒随机冒出一个气泡。
  • 内容： 例如 +❤️ 心情、+✨ 快乐、+🌱 成长，使用 i18n 文本。
  • 视觉： 圆角小标签，白底半透明，带金色/粉色小图标，描边与游戏风格一致。
  • 动画： 从宠物头顶向上漂浮 30–40px，同时 opacity 从 1 → 0，持续 1.5s，然后移除。
  • 位置： 气泡从宠物中心略上方发出，水平偏移随机 ±10px，避免多个气泡重叠。
  • 收益预览（静态）： 空状态时不再显示底部收益卡片；当宠物在场时，用一个固定的小徽章显示“+心情/分钟”作为提示。

四、空状态设计
  • 背景保留森林场景（树冠、地面、萤火虫），但宠物区域显示一片飘落的叶子 🍃 作为占位。
  • 提示文字改为短句：「把宠物拖到这里玩耍」或 i18n 等价文本。
  • 文字下方加一个虚线圆圈，暗示“这里将会有一个宠物”。
