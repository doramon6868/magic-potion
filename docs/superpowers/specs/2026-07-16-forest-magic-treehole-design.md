# 魔法树洞 · 森林玩耍区视觉改造设计文档

**日期：** 2026-07-16  
**主题：** OutdoorPlay.vue（森林玩耍区）视觉与交互升级  
**状态：** 已确认，待实施  

---

## 1. 背景与目标

当前 `OutdoorPlay.vue` 是一个标准的圆角矩形卡片：标题、说明、宠物区、收益卡片自上而下排列。视觉上与中间的水晶球、下方的游猎区没有拉开足够的情绪差异，也缺少“魔法森林”应有的沉浸感。

本次改造目标：
1. 让森林区从“信息卡片”变成“树洞入口”，与水晶球世界形成连续感。
2. 与下方游猎区建立强烈对比：森林 = 有机 / 柔和 / 安全，游猎 = 几何 / 尖锐 / 危险。
3. 在不改变右侧面板整体布局（260px 宽、约 200px 高）的前提下完成升级。

---

## 2. 核心视觉概念

**“魔法树洞”**：森林玩耍区是水晶球右侧自然延伸出的一个被树冠框住的林间空地。顶部是手绘树冠轮廓，底部是草地覆盖，宠物站在中央被漏光照亮的位置。

### 2.1 与游猎区的对比表

| 维度 | 森林区（本次改造） | 游猎区（后续方向） |
|------|------------------|------------------|
| 轮廓 | 有机树冠 + 草地起伏 | 尖锐岩石 / 荆棘直线 |
| 主色 | 冷绿 + 金粉点缀 | 暗红 + 炭黑 |
| 动效语言 | 摇摆、漂浮、萤火虫聚集 | 闪烁、震动、火光脉冲 |
| 情绪 | 安全、生长、治愈 | 危险、紧张、未知 |

## 3. 详细规格

### 3.1 SVG 树冠轮廓（外包/后续替换）

树冠 SVG 将作为 `OutdoorPlay.vue` 容器顶部的装饰层，也可能作为 `clip-path` 的参考。

- **画布尺寸**：宽度 260px，高度 40–50px，建议视口 `0 0 260 48`。
- **风格**：手绘卡通，粗描边 2–3px，与现有 `TreeDecoration.vue` 保持一致。线条可略带抖动，避免过度平滑的贝塞尔曲线。
- **结构**：
  - 底部一条平直的“林冠底线”，作为与下方内容的分界线。
  - 上方 3 个圆润树冠团：左侧较小、中间最高最大、右侧中等，像云朵一样连在一起。
  - 每个树冠团内部用 2–3 条弧线暗示叶片层次，不画单片叶子。
- **配色**：
  - 填充：比主背景深半档的绿色，例如 `#4a8b6a`，不透明度 80–90%，方便透出后方光晕。
  - 描边：游戏主描边色 `#612315`（或 `--mp-ink`），2.5px。
  - 点缀：在树冠右侧或中间缝隙加 1–2 个金色小圆点（魔法果实），直径 4–5px，同色系描边。
- **输出要求**：扁平 SVG，单一路径或 2–3 个路径，不内嵌复杂渐变，方便后续用 CSS 变量调色。

> **注意：** 树冠 SVG 由外部工具/设计师加工，不在本次实施范围内。实施阶段先用简化占位 SVG 或 CSS 模拟轮廓，待素材到位后替换。

### 3.2 背景层次

用多层背景营造景深：

1. **远景**：偏冷的蓝绿雾气层（`#a7e6cf` 到 `#88d8b0` 的线性渐变）。
2. **中景**：主林绿色（`#88d8b0`），占据视觉中心。
3. **近景地面**：底部一条略深的绿色色带（`#6b9b7a` 或 `rgba(75,130,100,0.4)`）。
4. **漏光**：从顶部中心向下的淡金色径向光晕（`rgba(255,255,255,0.35)`），照亮宠物所在区域。

### 3.3 emoji 动态小生物

所有动态元素使用 emoji + CSS 动画，不引入额外图片资源。

| 生物 | Emoji | 数量 | 动画 | 出现时机 |
|------|-------|------|------|----------|
| 萤火虫 / 魔法孢子 | ✨ 或 🌟 | 3–4 个 | 缓慢上下漂浮 + 明暗闪烁，周期 4–6s，相位错开 | 始终显示 |
| 蝴蝶 | 🦋 | 1–2 只 | 沿柔和曲线飞行，翅膀轻微缩放，周期 8–10s | 宠物在场时显示 |
| 小瓢虫 / 甲虫 | 🐞 | 1 个 | 沿底部草丛缓慢爬行，偶尔停顿，周期 12s | 始终显示 |
| 飘落花瓣 / 叶子 | 🌸 或 🍃 | 2–3 片 | 从顶部旋转飘落到底部，周期 6–8s，循环 | 始终显示 |

**通用约束：**
- 所有生物使用 `position: absolute`、`pointer-events: none`，不影响拖拽交互。
- 动画默认播放，但需尊重 `prefers-reduced-motion`。

### 3.4 冒泡收益提示

当宠物在森林区玩耍时，以浮动气泡形式显示收益，取代原有的底部收益卡片。

- **触发时机**：宠物在场时，每 5–8 秒随机冒出一个气泡。
- **内容示例**：`+❤️ 心情`、`+✨ 快乐`、`+🌱 成长`，使用 i18n 键值。
- **视觉样式**：圆角小标签，白底半透明，带金色/粉色小图标，2px 描边。
- **动画**：从宠物头顶向上漂浮 30–40px，同时 `opacity` 从 1 过渡到 0，持续 1.5s，结束后移除 DOM。
- **位置**：气泡从宠物中心略上方发出，水平随机偏移 ±10px，避免重叠。
- **静态收益徽章**：当宠物在场时，在标题旁显示一个固定的小徽章“+心情/分钟”，作为玩法提示。

### 3.5 空状态设计

- 保留森林场景（树冠、地面、萤火虫、飘落花瓣）。
- 宠物区域显示一片缓慢旋转飘落的叶子 🍃 作为占位。
- 提示文字：`把宠物拖到这里玩耍`（使用 i18n）。
- 文字下方加一个虚线圆圈，暗示“这里将会有一个宠物”。

### 3.6 交互反馈

- **拖拽高亮**：取消整体 `scale` 脉冲，改为草丛轻微摆动 + 萤火虫向中心聚集 + 漏光变亮。
- **宠物放入**：触发一阵花瓣/叶子被惊起的粒子效果（3–5 片花瓣从宠物落点向外飘散）。
- **宠物拖出**：短暂显示“召回”提示泡，然后宠物消失。

## 4. 信息层级调整

- **标题**：左对齐，使用 `🌲` 或树图标 + 区域名称。
- **安全标签**：右对齐，圆角胶囊，薄荷绿底色。
- **区域说明**：缩小字号至 11–12px，颜色使用 `--mp-text-muted`，只在需要时出现。
- **收益徽章**：作为标题旁的小标签，不占用底部空间。
- **冒泡收益**：作为宠物头顶的动态反馈。

---

## 5. 技术实现要点

1. **组件范围**：只修改 `src/components/OutdoorPlay.vue`，不改动 `App.vue` 的整体三栏布局。
2. **SVG 占位**：先用内联简化 SVG 或 CSS `border-radius` 模拟树冠轮廓，等待外部 SVG 完成后替换。
3. **粒子系统**：用纯 CSS `@keyframes` 实现，不引入新依赖。
4. **响应式**：保持现有 `@media` 断点行为，树冠轮廓在小屏幕下可适当简化。
5. **i18n**：新增或复用以下键：
   - `areas.forest.hint`（空状态提示）
   - `areas.forest.reward` 或新的收益冒泡键
6. **可访问性**：动画需尊重 `prefers-reduced-motion`；保持足够的颜色对比度。

- [ ] 萤火虫、蝴蝶、瓢虫、飘落花瓣等动态元素按规格运行。

- [ ] 空状态有叶子占位和拖放提示。
- [ ] 拖拽高亮和放入反馈符合“自然、柔和”的情绪。
- [ ] 响应式布局正常，动画尊重 `prefers-reduced-motion`。
