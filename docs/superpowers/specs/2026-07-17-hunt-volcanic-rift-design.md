# 火山裂隙 · 游猎区视觉改造设计文档

**日期：** 2026-07-17  
**主题：** OutdoorHunt.vue（户外游猎区）视觉与交互升级  
**状态：** 已确认，待实施  

---

## 1. 背景与目标

当前 `OutdoorHunt.vue` 仍采用早期设计：单一红色渐变卡片、两只平移蝙蝠、底部固定风险/收益面板。与刚完成「魔法树洞」改造的森林区相比，游猎区在视觉完成度、情绪表达和交互反馈上都有明显差距。

本次改造目标：
1. 让游猎区从「红色信息卡片」变成「火山裂隙入口」，与森林区形成「安全 vs 危险」的强对比。
2. 与水晶球、森林区保持统一的 Q 版手绘风格（粗描边、硬阴影、圆润可爱但情绪不同）。
3. 在不改变右侧面板整体布局（260px 宽、约 200px 高）的前提下完成升级。
4. 通过环境本身传达危险与收益，减少对文字警告的依赖。

---

## 2. 核心视觉概念

**「火山裂隙」**：游猎区是水晶球右侧地面突然裂开的一道小型火山口。宠物被拖拽到这里时，不是被放到卡片上，而是被放到裂口边缘进行战斗。裂口内部有暗红岩壁、岩浆裂纹、漂浮火星和硫磺烟雾。

### 2.1 与森林区的对比表

| 维度 | 森林区（已改造） | 游猎区（本次改造） |
|------|------------------|------------------|
| 轮廓 | 有机树冠 + 草地起伏 | 焦黑岩石剪影 + 锯齿裂口 |
| 主色 | 冷绿 #88d8b0 + 金粉点缀 | 暗红 #6B2D2D + 炭黑 + 岩浆金 #F59E0B |
| 动效语言 | 摇摆、漂浮、萤火虫聚集 | 闪烁、震动、火光脉冲、火星升腾 |
| 情绪 | 安全、生长、治愈 | 危险、紧张、未知 |
| 空状态 | 落叶 + 虚线放置圈 | 暗淡符文 + 未点燃火把 |
| 拖放反馈 | 花瓣爆发 + 草丛摆动 | 火星喷溅 + 裂纹高亮 |

## 3. 详细规格

### 3.1 裂口轮廓组件 CraterRim.vue

新增 SVG 装饰组件 `src/components/icons/decorations/CraterRim.vue`，贴在 `OutdoorHunt.vue` 容器顶部。

- **画布尺寸**：宽度 260px，高度 40–50px，建议视口 `0 0 260 48`。
- **风格**：手绘卡通，粗描边 2.5px，与现有 `TreeDecoration.vue`、`CanopyTop.vue` 保持一致。线条略带抖动，避免过度平滑。
- **结构**：
  - 底部一条平直的「裂口底线」，作为与下方内容的分界线。
  - 上方 2–3 个尖锐焦黑山峰：左侧较低、中间最高且带缺口、右侧一个小火山锥。
  - 顶部留 1–2 个缺口，让后方岩浆光透出来。
- **配色**：
  - 填充：`#3D1F1F` 或 `#4A2525`（深褐红），不透明度 90%。
  - 描边：游戏主描边色 `#612315`（或 `--mp-ink`），2.5px。
  - 缺口处可加极细的金色描边，暗示岩浆反光。
- **输出要求**：扁平 SVG，单一路径或 2–3 个路径，不内嵌复杂渐变，方便后续用 CSS 变量调色。

> **注意：** 裂口 SVG 可由外部工具/设计师精修，实施阶段先用简化占位 SVG 或 CSS 模拟轮廓，待素材到位后替换。

### 3.2 背景层次

用多层背景营造景深。颜色以暗红、炭黑、岩浆金为主，不强制绑定到已有 token：

1. **顶层烟幕/漏光**：`radial-gradient(ellipse at 50% 0%, rgba(255,160,80,0.15), transparent 60%)` —— 模拟裂口上方的硫磺热气。
2. **远景岩壁**：`linear-gradient(180deg, #5C2A2A 0%, #4A2020 40%)` —— 裂隙后方的暗红岩壁。
3. **中景主色**：`linear-gradient(180deg, #6B2D2D 40%, #4A1A1A 100%)` —— 火山口内部。
4. **近景灰烬带**：底部 28px 高的深色带 `rgba(30,20,20,0.6)`，覆盖在主色之上。
5. **岩浆裂纹**：在灰烬带和中景交界处嵌入 2–3 条发光的金红色裂纹，宽度 60–80%，水平居中。

如果项目已有 token 能覆盖这些颜色，优先复用 token；否则以十六进制值作为过渡方案。

### 3.3 动态元素

所有动态元素优先使用 CSS/SVG 动画，不引入额外图片资源。

| 元素 | 形态 | 数量 | 动画 | 出现时机 |
|------|------|------|------|----------|
| 火星/余烬 | 4–8px 金色圆点 | 4–6 个 | 从底部向上漂浮，边飘边变小、闪烁，周期 3–5s，相位错开 | 始终 |
| 烟雾 | 半透明椭圆或 💨 | 2–3 团 | 从裂口两侧升起、扩散、淡出，周期 6–8s | 始终 |
| 岩浆裂纹光 | CSS 伪元素或 div | 2–3 条 | 明暗脉动，周期 2–3s，相位错开 | 始终 |
| 小恶魔/火蝠 | 复用 BatDecoration 改色 | 2 只 | 沿锯齿状路径飞行，周期 5–7s | 始终 |
| 硫磺闪光 | 顶部缺口处光点 | 1–2 个 | 间歇性强光闪烁，周期 4–6s | 始终 |
| 战斗震动 | 容器整体 | 1 | 快速微幅 shake，周期 0.2–0.25s | 宠物在场时 |

**通用约束：**
- 所有动态元素使用 `position: absolute`、`pointer-events: none`，不影响拖拽交互。
- 动画默认播放，但需尊重 `prefers-reduced-motion`。

**关键动画定义：**

```css
/* 火星上升 */
@keyframes ember-rise {
  0%   { transform: translateY(0) scale(1); opacity: 0; }
  10%  { opacity: 0.9; }
  80%  { opacity: 0.6; }
  100% { transform: translateY(-120px) scale(0.2); opacity: 0; }
}

/* 岩浆裂纹脉动 */
@keyframes lava-pulse {
  0%, 100% { opacity: 0.4; box-shadow: 0 0 4px rgba(245, 158, 11, 0.3); }
  50%      { opacity: 1;   box-shadow: 0 0 12px rgba(245, 158, 11, 0.8); }
}

/* 战斗震动 */
@keyframes hunt-shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-1px); }
  75% { transform: translateX(1px); }
}
```

### 3.4 信息层级

#### 标题区

参考森林区 layout，改为左/中/右三段式：

```
[🗡️ 游猎区]        [危险]    [金币 +50~100]
```

- **左侧**：短剑/火把图标 + 区域名称 `areas.hunt.name`。
- **中间**：危险标签 `areas.hunt.tag`，背景 `--mp-red` 半透明，深棕描边。
- **右侧**：收益徽章 `areas.hunt.reward`，金色边框，放在标题行，不占用底部空间。

#### 区域说明

- **空状态时显示**：第一行 `areas.hunt.description`，第二行 `areas.hunt.warning`（红色加粗）。
- **宠物在场时隐藏说明**，减少信息干扰，让视觉重心集中在火山场景和宠物上。

#### 底部风险/收益面板

移除现有的 `.reward-preview` 底部面板。收益上移到标题右侧徽章，风险在空状态时通过说明文字展示，宠物在场时通过环境紧张感传达。

### 3.5 空状态设计

保留火山场景（岩石剪影、火星、烟雾、裂纹），宠物区域显示：

- **未点燃的符文圈**：56px 虚线圆环，颜色 `rgba(245, 158, 11, 0.4)`，缓慢旋转，暗示「这里需要被点燃」。
- **小火把图标**：🕯️ 或自定义 SVG，放在圆环上方，火焰暗淡摇曳。
- **提示文字**：`拖拽宠物来战斗`（使用 `areas.hunt.hint`）。

### 3.6 交互反馈

#### 拖放高亮

当用户拖拽宠物到游猎区时：

- 岩石边缘描边变亮为金色 `--mp-gold`；
- 火星数量增加、上升速度加快；
- 岩浆裂纹亮度增强、脉动加快；
- 容器整体发出红色火光 `box-shadow: 0 0 30px rgba(220, 38, 38, 0.5)`；
- 不使用整体 scale，改用「热量积聚」的感觉。

#### 宠物落下反馈

宠物被放到裂口时触发一次 **岩浆喷溅**：

- 3–5 个火星从落点向四周爆开；
- 底部裂纹同时高亮 0.3s；
- 小恶魔/火蝠被惊飞，飞行速度临时加快 1s。

#### 战斗结果反馈

根据战斗结果在区域内做即时视觉反馈：

**胜利**
- 裂口喷出金币火花（金色粒子向上飞散）；
- 岩浆裂纹变成亮金色 1s；
- 顶部岩石缺口有金光闪过。

**失败/死亡**
- 火光瞬间熄灭，烟雾变浓；
- 屏幕边缘变暗 0.5s；
- 小恶魔四散飞走；
- 宠物状态变为 `dead` 动画（如 PetAvatar 支持）。

## 5. 技术实现要点

1. **组件范围**：
   - 修改 `src/components/OutdoorHunt.vue`；
   - 新增 `src/components/icons/decorations/CraterRim.vue`；
   - 可复用现有 `BatDecoration.vue` 作为火蝠，通过 CSS filter 或新增 prop 调整颜色。
2. **SVG 占位**：先用内联简化 SVG 或 CSS 模拟裂口轮廓，等待外部 SVG 完成后替换。
3. **粒子系统**：火星喷溅、金币火花用纯 CSS `@keyframes` 实现，不引入新依赖。
4. **响应式**：保持现有 `@media` 断点行为，裂口轮廓在小屏幕下可适当简化。
5. **可访问性**：
   - 动画需尊重 `prefers-reduced-motion: reduce`，禁用震动、火星、烟雾动画；
   - 保持足够的颜色对比度，确保危险标签、收益徽章文字可读。
6. **性能**：
   - 火星/烟雾使用 `will-change: transform, opacity`；
   - 动态元素总量控制在 10 个以内，避免过多重绘。
