## 1. 项目背景与目标

### 1.1 背景

《Magic Potion / 魔法药水》是一款以紫色水晶球为核心交互载体的轻度宠物养成游戏。当前 Web MVP 已完成，但界面仍以 emoji 和 pastel 渐变为主，视觉表现较为简单，未能充分体现游戏的魔法主题和卡通感。

### 1.2 目标

通过本次改造，让游戏界面整体升级为 **Q版手绘卡通风格**：

- **更卡通化**：所有视觉元素采用圆润、可爱、手绘质感的设计语言
- **减少 emoji**：将核心宠物、道具、装饰全部替换为自定义 SVG 图形
- **更生动的动画**：宠物状态动画、拖拽反馈、水晶球环境动画、界面转场、动态背景全面提升
- **可逆改造**：在独立分支 `feature/hand-drawn-ui-redesign` 上实施，不影响主分支稳定性

### 1.3 非目标

- 不修改游戏核心逻辑、数值平衡、状态管理（Pinia stores）
- 不修改拖拽交互的数据流（仍使用 HTML5 Drag API）
- 不新增游戏系统或玩法
- 不修改 i18n 文案键值（可能新增 UI 相关文案）

## 2. 视觉设计系统

### 2.1 设计关键词

Q版手绘、魔法药水、水晶球、剪纸贴纸感、圆润可爱、活泼明亮

### 2.2 色彩系统

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 魔法紫 | `#8B5CF6` | 主按钮、标题、水晶球边框、强调色 |
| 薰衣草 | `#A78BFA` | 面板背景渐变、悬停状态、装饰 |
| 薄荷绿 | `#7DD3C0` | 森林区、健康条、安全提示 |
| 软糖粉 | `#F472B6` | 心情条、心情道具、爱心元素 |
| 金币黄 | `#FBBF24` | 金币、特殊道具、高亮、警告提示 |
| 警告红 | `#F87171` | 游猎区危险、死亡提示 |
| 泡泡蓝 | `#60A5FA` | 信息提示、稀有道具 |
| 手绘深棕 | `#612315` | 所有描边、文字、图标轮廓 |
| 云朵白 | `#FFFFFF` | 卡片底色、云朵、高光 |
| 背景浅紫 | `#F5F0FF` | 页面底色、柔和背景 |

### 2.3 形态语言

- **描边**：所有重要元素使用 `3px #612315` 手绘深棕描边，模拟手绘勾线
- **阴影**：使用 4-5px 硬偏移阴影（如 `box-shadow: 4px 4px 0 rgba(97,35,21,0.15)`），营造剪纸/贴纸感，避免柔和弥散阴影
- **圆角**：大面板 `20-24px`，按钮 `24px`（胶囊形），小卡片 `14-16px`，水晶球保持正圆
- **渐变**：使用柔和的线性渐变，避免强烈对比
- **字体**：保持系统字体，标题加粗（700），正文 400-500，小标签 12px

## 3. 组件改造计划

整体布局保持**三栏结构**：左侧宠物面板、中央水晶球、右侧户外区。所有组件在保留原有功能和数据流的基础上，进行视觉风格重绘。

### 3.1 顶部栏 TopBar

- 改为漂浮的魔法卷轴/横幅形状，两端有卷起效果
- 金币显示改为带旋转光效的**金币袋 SVG**
- 商店、存档按钮改为**圆形魔法贴纸按钮**，悬停时弹跳
- 标题保留「Magic Potion」，字体加粗并带轻微光晕

### 3.2 左侧宠物面板 PetDisplay

- 外框改为带蝴蝶结/星星装饰的**魔法相框**
- 宠物头像改为 **SVG 手绘蛞蝓猫**，不同宠物类型对应不同配色：
  - 猫：薄荷绿渐变
  - 鸟：泡泡蓝渐变
  - 狐：暖橙渐变
  - 龙：淡紫渐变
- 属性条改为带图标的**糖果色进度条**
- 背包区域物品网格改为**手绘贴纸式卡片**
- 切换宠物按钮改为小魔杖/星星图标

### 3.3 中央水晶球 CrystalBall

- 保留并强化现有的 **ObservatoryDome 穹顶开合** 和 **MagicDoor 水膜涟漪** 效果
- 水晶球本体加入**呼吸光晕**和内部漂浮粒子
- 球内宠物添加「被玻璃轻微折射」的模糊效果
- 拖拽物品接近时，旋涡变成**金色吸入动画**
- 合成入口按钮改为带魔药瓶图标的漂浮按钮

### 3.4 右侧户外区 OutdoorPlay / OutdoorHunt

**森林区 OutdoorPlay：**
- 绿色草地背景 + 摇摆的树木/花朵 SVG
- 阳光光斑和飘浮花粉粒子
- 可放置时显示绿色波纹扩散高亮

**游猎区 OutdoorHunt：**
- 暗红色岩石背景 + 篝火 SVG
- 漂浮的骷髅/蝙蝠 SVG，营造危险氛围
- 可放置时显示红色火焰状高亮

### 3.5 物品组件 Item

- 完全移除 emoji 图标
- 每个物品类型对应一个 SVG 图标组件
- 普通/优秀/稀有/史诗边框按稀有度着色
- 数量徽章改为圆润气泡
- 风味文本保留但改为更小字号

### 3.6 弹窗组件

**商店 Shop：**
- 弹窗外框改为魔法书页/卷轴卡片
- 商品分类标题改为带图标的魔法标签
- 商品卡片改为贴纸风格，购买按钮为胶囊形

**合成 SynthesisUI：**
- 保留三栏布局
- 宠物预览、碎片、药水全部改为 SVG 图标
- 成功率显示加入动态进度环
- 合成动画阶段加入更华丽的旋涡/光芒效果

**存档管理 SaveManager：**
- 改为书架/卷轴风格
- 存档位改为带有日期标签的魔法卷轴卡片

### 3.7 通知栏 NotificationBar

- 消息改为从魔法瓶中冒出的气泡
- 不同状态用不同颜色 + 对应小图标（成功=绿色星星，警告=黄色闪电，错误=红色爱心碎裂，信息=蓝色水滴）

## 4. SVG 资源策略

### 4.1 方案

采用 **Vue 图标组件 + 少量 CSS 装饰图形** 的混合方案：

- 复杂或需要复用的图形封装为独立 Vue 组件
- 简单装饰（云朵、星星、光点）使用 CSS 渐变和伪元素实现
- 不使用外部图标库，保证风格统一

### 4.2 新增 SVG 组件清单

### 4.3 宠物表情状态

`SlugcatAvatar.vue` 通过 prop 接收状态，切换不同表情：

- `idle`：睁眼微笑，轻微呼吸
- `happy`：闭眼笑，带腮红
- `sleeping`：闭眼，Zzz 符号
- `tired`：耷拉眼皮/耳朵
- `sad`：流泪
- `eating`：张嘴咀嚼
- `playing`：兴奋睁大眼
- `hunting`：紧张表情
- `dead`：幽灵/晕倒

## 5. 动画计划

### 5.1 宠物状态机动画

| 状态 | 动画效果 | 时长 |
|------|---------|------|
| idle | 轻微上下浮动 + 耳朵微动 | 2s 循环 |
| happy | 跳跃 + 星星粒子爆出 | 0.6s |
| sleeping | 左右摇摆 + Zzz 漂浮 | 3s 循环 |
| tired | 身体压低 + 缓慢呼吸 | 2.5s 循环 |
| sad | 轻微颤抖 + 眼泪滴落 | 2s 循环 |
| eating | 嘴巴咀嚼 + 食物碎屑 | 0.4s |
| playing | 快速左右摇摆 | 0.3s 循环 |
| hunting | 紧张抖动 | 0.2s 循环 |
| dead | 透明闪烁 + 幽灵飘动 | 3s 循环 |

### 5.2 拖拽反馈动画

- 拖拽开始时：元素半透明 + 放大 1.05 + 光点环绕
- 拖拽过程中：跟随鼠标产生残影帧
- 放置到水晶球：物品沿抛物线飞向中心，被旋涡吸入消失
- 放置到户外区：宠物从水晶球飞出，户外区产生弹跳入场
- 放置无效时：元素弹性回弹

### 5.3 水晶球环境动画

- 呼吸光晕：球体轻微缩放 + 光晕强弱变化
- 内部粒子：3-5 个小光点缓慢环绕
- 穹顶开合：开合时边缘发出金光
- 水膜涟漪：开门时两侧水膜波动 + 水花飞溅
- 旋涡动画：多层反向旋转 + 中心脉动

### 5.4 动态背景动画

在 `App.vue` 或新增 `MagicBackground.vue` 中实现：

- 多层缓慢飘动的云朵（不同速度产生视差）
- 随机闪烁的星星
- 底部若隐若现的漂浮岛屿
- 偶尔划过的流星

### 5.5 界面转场动画

- 弹窗打开：从中心弹性缩放进入
- 弹窗关闭：缩小淡出
- 通知进入：从底部滑入带轻微弹跳
- 通知离开：向上淡出
- 按钮点击：按下后回弹
- 面板切换：淡入淡出 + 轻微位移

## 6. 布局与响应式

### 6.1 桌面端（>1024px）

保持三栏布局：

```
┌──────────────────────────────────────────────────────┐
│                    TopBar (卷轴横幅)                  │
├──────────────────┬──────────────────┬────────────────┤
│                  │                  │                │
│   PetDisplay     │   CrystalBall    │  OutdoorPlay   │
│   (魔法相框)      │   (水晶球)        │  (森林卡片)     │
│                  │                  ├────────────────┤
│                  │                  │  OutdoorHunt   │
│                  │                  │  (游猎卡片)     │
└──────────────────┴──────────────────┴────────────────┘
```

### 6.2 平板端（768px - 1024px）

- 顶部栏增加快捷入口
- 左右面板折叠为顶部快捷栏或侧边抽屉
- 中央水晶球保持主要显示区域

### 6.3 移动端（<768px）

- 改为垂直堆叠布局
- 宠物面板 → 水晶球 → 户外区
- 户外区可横向滑动或改为标签切换

## 7. 实施策略

### 7.1 分支管理

- 从 `main` 切出分支：`feature/hand-drawn-ui-redesign`
- 所有 UI 改造在该分支完成并测试后再合并
- 用户可在浏览器中随时切换分支查看效果

### 7.2 改造顺序

建议按以下顺序实施，每阶段都可独立运行验证：

1. **视觉系统搭建**
   - 在 `index.html` 更新 CSS 变量
   - 创建设计 token 文件（可选 `src/styles/design-tokens.css`）

2. **SVG 图标组件**
   - 创建 `src/components/icons/` 目录
   - 先实现宠物、食物、道具核心图标

3. **背景与布局**
   - 添加动态背景组件
   - 调整 App.vue 布局样式

4. **核心组件改造**
   - TopBar
   - PetDisplay
   - CrystalBall（含 dome/door 优化）
   - OutdoorPlay / OutdoorHunt

5. **物品与弹窗改造**
   - Item.vue
   - Shop.vue
   - SynthesisUI 系列
   - SaveManager.vue
   - NotificationBar.vue

6. **动画增强**
   - 宠物状态动画
   - 拖拽反馈动画
   - 界面转场动画

### 7.3 文件影响范围

主要修改文件：

- `index.html` — 更新全局 CSS 变量和背景
- `src/App.vue` — 布局、背景组件引入
- `src/components/*.vue` — 大部分 UI 组件
- 新增 `src/components/icons/` — SVG 图标组件
- 新增 `src/components/MagicBackground.vue` — 动态背景
- 新增 `src/styles/design-tokens.css` — 设计 token（可选）

不修改文件：

- `src/stores/*.js` — 状态管理
- `src/config/*.js` — 配置数据
- `src/i18n/locales/*.json` — 可能新增 UI 文案，但不改现有键

### 7.4 测试策略

- 每改造一个组件后运行 `npm run dev` 验证渲染
- 验证拖拽交互未被破坏
- 验证中英文切换正常
- 验证商店购买、合成、存档等弹窗正常打开
- 使用浏览器 DevTools 检查动画性能

## 8. 风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| SVG 组件过多导致维护复杂 | 中 | 建立清晰的图标目录结构，复用基础图形 |
| 动画过多导致性能下降 | 中 | 使用 CSS 动画优先，减少 JS 驱动动画；复杂动画仅在桌面端启用 |
| 触摸设备拖拽体验差 | 中 | 改造后测试移动端拖拽，必要时添加 touch 事件支持 |
| 设计风格与现有功能不搭 | 低 | 每阶段都进行视觉验收，及时调整 |
