风格规则
描边：所有重要元素使用 3px #612315 手绘深棕描边，模拟手绘勾线。重要按钮/标题可加 3px 深色描边。
阴影：使用 4-5px 的硬偏移阴影（box-shadow: 4px 4px 0 rgba(...)），营造剪纸/贴纸感，避免柔和的弥散阴影。
圆角：大面板 20-24px，按钮 24px（胶囊形），小卡片 14-16px，水晶球保持正圆。
字体：保持系统字体，标题加粗（700），正文 400-500，小标签 12px。
